# 潦草小抄 · scrawl-sheet

把整理好的笔记渲染成“考前手抄小抄”：狂野的手写字体、不均匀的墨水、歪斜的行、写错涂掉的字、荧光笔、折痕……而且字可以小到 4–6pt，整页密密麻麻。

纯前端，没有依赖（只用 Vite 开发），所有效果都在 `<canvas>` 上逐像素做出来。

```bash
npm install
npm run dev      # 本地开发
npm run build    # dist/ + 单文件版 dist/scrawl-sheet.html（双击即可打开，联网加载字体）
```

## 输入格式

```
# 标题            整页最上面的大标题
## 小节           小节标题（随机：下划线 / 方框 / 荧光笔 / 双下划线）
- 要点            项目符号（缩进两个空格 = 下一级）
1. 编号
> 注意            手画方框（连续几行共用一个框）
---              波浪 / 手画分割线

**粗**  ==荧光笔==  __下划线__  !!红笔圈出来!!  ~~划掉~~
->  =>  <=>  <-   画成手写箭头
X̄  θ̂             组合字符的上划线 / 帽子由“笔”画上去，而不是依赖字体
```

## 它是怎么做到“像手写”的

假手写最大的破绽是**同一个字母每次都长得一模一样**。下面每一层都在打破这种一致性：

1. **混字体** (`engine/presets.js`)：每种“笔迹”混用 2–3 款相近的手写字体（Caveat、Nanum Pen Script、Reenie Beanie……中文用 Long Cang / 志莽行书 / 刘建毛草），按词随机挑。
2. **逐字抖动** (`engine/layout.js` → `prepareUnits`)：每个字有自己的旋转、缩放、上下偏移、斜体角度、字距、墨色深浅；10–35% 的字会“描两遍”，粗细不均。
3. **行是歪的**：每行有自己的斜率和一条慢正弦波，行首左右漂移；整页再叠一层低频噪声位移（`warp`），所有线、圈、箭头也跟着一起弯。
4. **真实的“挤”**：行尾放不下时先把最后一个词压扁再说，实在不行才换行；可选“越写越小”；自动二分查找能把全部内容塞进一页的最大字号。
5. **墨水** (`engine/ink.js`)，三遍像素处理：
   - 位移：两层噪声推像素——约半个字宽的中频噪声让笔画本身变形（同一个字母再也不会一样），几个像素的高频噪声把边缘啃毛；
   - 洇墨：对预乘 alpha 做盒式模糊；
   - 重新上墨：用软阈值把模糊后的 alpha 收回来（笔画中心积墨、边缘发毛），再乘上墨量不均、圆珠笔断墨、铅笔纸纹。
6. **笔的痕迹** (`engine/pen.js`)：下划线、红圈、方框、箭头、分栏线都是带抖动和过冲的折线；写错的词先写一个拼错的版本再乱涂掉；随机的下笔墨点、墨渍和飞溅；手蹭过未干墨水的拖影。
7. **纸和成品** (`engine/paper.js`, `engine/finish.js`)：方格 / 横线 / 点阵 / 黄拍纸 / 牛皮纸，加纸纹噪声；做旧会对折出折痕、加咖啡杯印和霉斑；最后可以“平铺扫描”、“手机拍照”（桌面、阴影、偏色、暗角）或“复印件”（高对比、碳粉点）。

所有随机都来自同一个种子，同样的内容 + 参数 + 种子永远画出同一张图；“换个写法”就是换种子。
